# 需求澄清 — OOK Shaped Polar 验证

## 需求一句话概述

在 `v2` 主线中建立 OOK 二元 shaped-polar 正确性验证，先验证 2018 年论文第二节的整形机制，而不复现其 4-ASK/16-ASK 性能图。

## 功能细节

- 本阶段的对象是 OOK：比特 `1` 为高电平，目标概率定义为 `p=P_X(1)`。
- 正式扫描 `p=[0.5,0.6,0.7,0.8,0.9]`；`p>0.5` 用于体现高电平符号占比提高带来的能量优势。
- `p` 的熵与 BSC 构造使用等价交叉概率 `q=min(p,1-p)=1-p`；实现必须清楚区分 `p=P_X(1)` 与 `q`，不得把 `BSC(0.9)` 当作普通交叉信道。
- precoder 与通信接收端 decoder 均使用 SC；本阶段不引入 SCL、CRC 或 4/16-ASK。
- BER 图的每个 `(p,SNR)` 点重新进行 GA 通信可靠性构造；图必须标注为逐 SNR 自适应构造，不能误读为同一码跨 SNR 曲线。
- 保留 `ShapedPolarS` 的逐码字 `spow` 归一化：每条 OOK 码字按 `spow=mean(c.^2)` 设置噪声方差，以固定该帧 `E_s/N_0`；GA 与通信 SC LLR 使用 legacy `sigma_ga=10^(-SNR/20)`，该混合口径须完整记录。
- 保留 `ShapedPolarS` 的单码字统计量 `p_encoded=sum(c==1)/N`，作为与历史脚本的直接对照指标。
- 正式判断不能只看单码字：每个目标 `p` 必须生成多条独立码字，保存所有 `p_encoded`，统计均值、标准差与 95% 置信区间；目标 `p` 落在该置信区间内才判定整形比例通过。
- 本阶段还须验证无噪声译码、OOK AWGN LLR 口径和集合构造；这些验证服务于后续 BER/Goodput/Energy 定量分析。

## 验收标准

- [ ] 所有 `p=[0.5,0.6,0.7,0.8,0.9]` 均输出逐码字 `p_encoded` 原始样本、均值、标准差和 95% 置信区间。
- [ ] 对每个 `p`，目标 `p` 位于其独立码字样本均值的 95% 置信区间内。
- [ ] `p=0.5` 时 `S=0`，退化为无整形基线；结果与该退化关系一致。
- [ ] 集合构造、先验 LLR、OOK 发射幅度、噪声方差和接收端 LLR 的定义均在 README/结果元数据中可追溯。
- [ ] 无噪声链路对每个 `p` 都恢复全部信息位；异常输入（非法 `p`、非 `2^n` 块长、维度不匹配）被明确拒绝或报告。
- [ ] 产物写入时间戳 `16QAM_Polar/v2/results/` 目录，包含参数/种子、CSV/MAT、README、日志和图。

## 超出范围（不做的事）

- 不复现《Shaped Polar Codes for Higher Order Modulation》第五节的 4-ASK/16-ASK、SCL=32、CRC 性能图。
- 不在本阶段声称 BER、Goodput 或能量策略最优。
- 不把 `16QAM_Polar/OOK/` 的 legacy 曲线直接视为论文正确性的证据。
- 不自动执行长时间 Monte Carlo；完整运行由用户授权后在本地执行。

## 技术路线提示

- 正式代码放在 `16QAM_Polar/v2/experiments/ook_shaped_polar/`。
- 验证与计划文档放在 `学习文档/shaped_polar验证loop/`。
- 以论文第二节的二元偏置码字机制为理论基准，以 `ShapedPolarS` 的 `p_encoded` 统计方式为 legacy 对照，但不继承其未验证的集合/SNR/LLR 口径。

## 假设与风险

- 假设 `1` 始终表示 OOK 高电平；若调制映射改变，`p` 的物理含义和能量解释必须同步调整。
- 论文中 `BSC(p)` 的符号与本项目 `p=P_X(1)>0.5` 不是同一对象；实现必须保留 `q=1-p` 的显式命名和记录。
- 单码字比例存在有限长度波动；必须使用独立消息样本统计，不能只复刻 legacy 的一次 `p_encoded` 打印。
- SC precoder 的有限长度整形误差可能大于 SCL；本阶段目标是建立 SC 口径的正确性，不以 SCL 最佳性能作为验收。
