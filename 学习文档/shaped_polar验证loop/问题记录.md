# 问题记录 — OOK Shaped Polar 验证

> 编号连续且不跳号。问题解决后将标题中的 🔴 / 🟡 改为 🟢，并保留根因与处理记录，避免接手人误判。

## 1. legacy 集合构造与论文第二节不一致 🟡

- **背景/现象**：`ShapedPolarS/gettest.m` 以同一目标 AWGN 的 GA 排序同时选择 shaping set 与信息集；论文要求 shaping set 先按 BSC(`q`) 构造，再在目标信道上排除 shaping set 选择信息集。
- **风险**：即使 `p_encoded` 接近目标值，仍不能证明集合构造符合论文机制。
- **决策修法**：正式 v2 验证线按协议分离 BSC(`q_bsc`) 与 OOK/AWGN 的构造口径；legacy 只用于 `p_encoded` 指标与历史趋势对照。
- **状态**：待公共底座实现后关闭或拆分为实现问题。

## 2. legacy OOK 噪声与 LLR 方差口径未统一 🟡

- **背景/现象**：旧脚本的实际加噪方差和 LLR 使用的 `sigma` 不是明确同一量，难以判定其 SNR/LLR 是否匹配。
- **风险**：BER 曲线形态可能源自失配，而非 shaped-polar 机制。
- **决策修法**：正式实现用协议中的 `x=a*c`、`sigma_noise` 和解析 `L_ch`，并对同一点进行数值似然核对。
- **状态**：待公共底座实现后关闭。

## 3. SC 有限长度的目标概率可能不落入 CI 🟡

- **背景/现象**：论文示例用 SCL=32 precoder；本阶段按用户要求固定 SC，强偏置下可能产生有限长度失配。
- **风险**：不能把 SC 的失配藏在单码字或更改目标 `p` 中。
- **决策修法**：保留所有样本和失败点；若 CI 不包含目标值，先进行 `S_size` 标定扫描并报告，不擅自改用 SCL。
- **状态**：待 `p=0.6…0.9` 校准结果决定。

## 4. SC precoder 必须以当前消息为条件 🟡

- **背景/现象**：legacy 脚本先独立生成 shaping bits，再填入随机信息位，不能保证整形位在当前信息消息条件下生成。
- **决策修法**：新 API 显式传入 `I_set` 信息位与 `F_set` frozen values；新增双消息差异验证。
- **状态**：待公共底座实现后关闭。

## 5. 每个 SNR 点的 GA 自适应构造必须可追溯 🟡

- **背景/现象**：BER 图每个横轴 SNR 都重新 GA 构造 I/F，而 S_set 只由 p 决定。
- **决策修法**：保存每个 `(p,SNR)` 的 `sigma_ga`、S/I/F 索引摘要和集合检查；图表明确不是同一码跨 SNR 曲线。
- **状态**：待 BER 入口实现后关闭。
