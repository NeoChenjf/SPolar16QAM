# 问题记录 — OOK Shaped Polar 验证

> 编号连续且不跳号。问题解决后将标题中的 🔴 / 🟡 改为 🟢，并保留根因与处理记录，避免接手人误判。

## 1. legacy 集合构造与论文第二节不一致 🟡

- **背景/现象**：`ShapedPolarS/gettest.m` 以同一目标 AWGN 的 GA 排序同时选择 shaping set 与信息集；论文要求 shaping set 先按 BSC(`q`) 构造，再在目标信道上排除 shaping set 选择信息集。
- **风险**：即使 `p_encoded` 接近目标值，仍不能证明集合构造符合论文机制。
- **决策修法**：正式 v2 验证线按协议分离 BSC(`q_bsc`) 与 OOK/AWGN 的构造口径；legacy 只用于 `p_encoded` 指标与历史趋势对照。
- **状态**：待公共底座实现后关闭或拆分为实现问题。

## 2. legacy OOK 噪声与 LLR 方差口径未统一 🟡

- **背景/现象**：旧脚本的实际加噪方差和 LLR 使用的 `sigma` 不是明确同一量，难以判定其 SNR/LLR 是否匹配。
- **风险**：BER 曲线形态可能源自失配，而非 shaped-polar 机制。
- **决策修法**：正式实现用协议中的 `x=a*c`、`sigma_noise` 和解析 `L_ch`，并对同一点进行数值似然核对。
- **状态**：待公共底座实现后关闭。

## 3. SC 有限长度的目标概率可能不落入 CI 🟡

- **背景/现象**：论文示例用 SCL=32 precoder；本阶段按用户要求固定 SC，强偏置下可能产生有限长度失配。
- **风险**：不能把 SC 的失配藏在单码字或更改目标 `p` 中。
- **决策修法**：保留所有样本和失败点；若 CI 不包含目标值，先进行 `S_size` 标定扫描并报告，不擅自改用 SCL。
- **状态**：待 `p=0.6…0.9` 校准结果决定。

## 4. SC precoder 必须以当前消息为条件 🟡

- **背景/现象**：legacy 脚本先独立生成 shaping bits，再填入随机信息位，不能保证整形位在当前信息消息条件下生成。
- **决策修法**：新 API 显式传入 `I_set` 信息位与 `F_set` frozen values；新增双消息差异验证。
- **状态**：待公共底座实现后关闭。

## 5. 每个 SNR 点的 GA 自适应构造必须可追溯 🟡

- **背景/现象**：BER 图每个横轴 SNR 都重新 GA 构造 I/F，而 S_set 只由 p 决定。
- **决策修法**：保存每个 `(p,SNR)` 的 `sigma_ga`、S/I/F 索引摘要和集合检查；图表明确不是同一码跨 SNR 曲线。
- **状态**：待 BER 入口实现后关闭。


## 2026-10-09 追加：构造版本与问题状态

本轮针对原通信 GA 排序没有保证 $S$ 位于源低熵位置、$I$ 位于源高熵位置的问题，采用“源条件熵选择 $S$、剩余位置按信道 GA 选择 $I/F$”的固定计数构造；每个 SNR 的 GA 选择仍需重算，整形位仍按当前 payload 条件化。源熵估计与独立评估使用不同种子。新旧正式性能差异尚须由本轮 full-chain 数据确认，不能仅凭集合熵或 PMF 门禁推出 BER、Goodput 或收能结论。旧定位保留为历史证据，最新适用性及未决问题见[本轮清单](理论更新与图重建/整形理论更新与仿真图重建清单.md)。

## 2026-10-09 最终构造审计与F19理论差距

固定K与$|S|$后，独立精确源条件熵估计选S，剩余位置逐SNR采用信道GA选I/F，编码端按当前payload与F=0逐帧执行条件化precoding。正确集合下N=64合同测试通过：S/I/F互斥完备、大小正确、GA top-K I在S之外、全零/全一/两种固定seed随机payload均无噪声SC恢复正确，且full-chain导出的`I_by_snr`逐点与独立重算一致。旧构造入口保持兼容；`run_single`旧路径本轮smoke完成。

F19 code-only正式图：`16QAM_Polar/v2/results/20261009_202540_phaseA_codeonly_gap_analysis/figures/`。普通SC接收端不额外加源先验，刻意固定此口径隔离集合构造；N1024、5次重复中，SNR标签3 dB仿真/理论BER比值p=.5/.4/.3/.2/.1分别约131/66.6/22.9/9.78/1.37，3.25 dB分别约91.8/129/33.4/11.2/1.52。故当前理论估计明显低估p≥.2的仿真BER，不能直接作为绝对BER约束或优化预测。单载波实际Es/N0标签口径与该code-only低SNR网格并非同一横轴定义，应分别读README。

边界：本次完成的是新构造一致性和已登记数据下图重建；尚未完成匹配先验/源条件可靠性模型。F19不证明渐近收敛，也不支持将差距单归因于冻结位。

## 2026-10-09 F19 code-only理论差距重建

F19由source-entropy S集合、余位GA选I、实际I索引直接传入BER估计后重建。结果：`16QAM_Polar/v2/results/20261009_193607_phaseA_sc_final_global_curves/`保存五次重复及实际理论集合，后处理图/汇总在`20261009_202540_phaseA_codeonly_gap_analysis/`。在SNR标签3 dB，仿真/理论BER比值p=.5/.4/.3/.2/.1约131/66.6/22.9/9.78/1.37；3.25 dB约91.8/129/33.4/11.2/1.52。当前近似模型对p≥.2的绝对BER明显过于乐观，不适合直接当优化约束；小p走势相对接近但仍不能视为精确预测。普通SC接收度量没有额外源先验，码长/集合与构造改变均须控制，冻结位F=0不是唯一已证实原因。F19已通过集合索引、5重复、原始错误/帧数、图数值及视觉检查。

接下来P2拆开验证实际源PMF下的匹配接收度量与bit-channel可靠性，并记录模型适用边界；不以新增闭式BER为这轮完成条件。


## 2026-10-24 S机制对照追加

原源熵选S、余位GA选I/F与消息条件化整形保持不变。新问题出在“取消S并冻结0”的对照：它可能固定输出位，不能当作均匀基线。保留原S/I/F并在S放独立公平辅助位，当前21组生成矩阵审计均支持均匀输出；接收端仍判决I与S，只统计I。

供体S取自另一独立消息，可保留S向量内部统计并打破当前消息配合，不预设均匀PMF。源条件低熵不等于跨消息的S边缘熵低。以上不推翻原PMF证据，也不证明P2预测/通信优势；正式预算未批准。见[当前结论](../多载波OFDM瑞利信道-loop/机制对照与P2/等功率机制与P2当前结论.md)。
