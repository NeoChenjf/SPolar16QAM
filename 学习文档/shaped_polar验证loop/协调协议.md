# 协调协议 — OOK Shaped Polar 验证

> 本文件是所有五个 `p` 单元的数值口径唯一裁判。若改变任一公式、字段或判定规则，必须先更新本文件，再重跑受影响单元的 smoke。

## 1. 概率与集合契约

| 名称 | 定义 | 约束 |
| --- | --- | --- |
| `p_target` | `P_X(1)`，OOK 高电平 `1` 的目标概率 | 本 loop 取 `0.5:0.1:0.9`。 |
| `q_bsc` | `min(p_target,1-p_target)` | 本 loop 的高电平偏置下 `q_bsc=1-p_target`。 |
| `h2(q)` | `-q log2(q)-(1-q)log2(1-q)` | `q=0` 或 `1` 时按连续极限处理；本 loop 不取端点。 |
| `S_size` | `ceil(N*(1-h2(q_bsc)))` | `p_target=0.5` 时必须为 0。 |
| `S_set` | BSC(`q_bsc`) 上最可靠的 `S_size` 个极化子信道 | 用 Bhattacharyya 递推；不得由 OOK-AWGN 排序替代。 |
| `I_set` | 当前横轴 SNR 的 GA 口径下、排除 `S_set` 后选出的信息集 | 与 `S_set` 不相交；每个 SNR 点重构。 |
| `F_set` | 剩余集合 | `S∪I∪F={1,…,N}` 且两两不交。 |

本 loop 固定 `N=1024` 与 `K=ceil((N-S_size)/2)`，输出字段 `rate_design='legacy_half_remaining'`，并硬检查 `S_size+K<=N`。

### 构造算法与索引约定

- **BSC**：从 `Z0=2*sqrt(q_bsc*(1-q_bsc))` 递推 `Zminus=2*Z-Z^2`、`Zplus=Z^2` 至长度 N，以最小 Z 为最可靠；索引必须用与 `polar_encoder` 相同的 bit-reversal 映射，并用 N=2/4 手工例检查。
- **GA**：对每个横轴 `snr_db` 调用现有 `GA(sigma_ga,N)`，其中 `sigma_ga=10^(-snr_db/20)`；删除 `S_set` 后，剩余最高 K 个为 `I_set`，其余为 `F_set`。因此每个 BER 点是逐 SNR 自适应构造。

## 2. 编码与统计契约

1. 信息位独立均匀生成；frozen bits 固定为 0，种子和是否固定跨帧必须记录。
2. SC precoder API 必须接收 `(prior_llr,S_set,I_set,F_set,info_bits,frozen_values)`；本帧信息位与冻结值都是已知 decision，仅 `S_set` 待 SC 决定。`L_prior=log((1-p_target)/p_target)`。
3. 组装 `u`：`I_set` 放本帧信息位，`S_set` 放消息条件化 precoder 输出，`F_set` 放冻结 bits；两条不同消息必须验证 shaping 输出或生成轨迹不恒定。
4. 单码字统计固定为 `p_encoded=sum(c==1)/N`。
5. 每个单元必须保存 `sample_id,p_target,q_bsc,p_encoded,S_size,K,seed`；基于独立码字样本计算：

```text
mean_p_encoded = mean(p_encoded)
std_p_encoded  = std(p_encoded)
CI95 = mean_p_encoded ± t_{0.975,n-1} * std_p_encoded/sqrt(n)
target_in_ci = (CI95_low <= p_target <= CI95_high)
```

校准 smoke 使用至少 100 条独立码字；正式校准使用至少 1000 条独立码字和不重复派生 seed，且 `CI95_half_width<=0.01`。对于 `std=0` 或样本数不足以估计 CI 的情况，必须报告“统计不可判定”，不可自动通过。

## 3. OOK-AWGN 与 LLR 契约

- OOK 映射固定 `a=1`，即 `0→0`、`1→1`。
- **legacy spow 归一化**：每条码字 `spow=mean(c.^2)`，`sigma_noise=sqrt(spow/(2*10^(snr_db/10)))`，再令 `y=c+sigma_noise*randn(N,1)`；这固定每帧 `E_s/N_0`，不是固定物理噪声方差模型。
- **GA / SC LLR**：`sigma_ga=10^(-snr_db/20)`；通信译码固定使用原脚本 `L_legacy=(1-2*y)/(2*sigma_ga^2)`。结果必须记录 `sigma_ga`、`spow`、`sigma_noise` 与该缩放关系。物理 `L_phys=(1-2*y)/(2*sigma_noise^2)` 仅作诊断列，不与 `L_legacy` 混用。

`validation_checks.csv` 至少包括 `check_name,status,expected,actual,details`。图、README 和周报必须明确它是“二元机制验证”、每个 SNR 的 BSC+GA 自适应构造，不是 4/16-ASK 论文性能复现或同一码跨 SNR 曲线。
