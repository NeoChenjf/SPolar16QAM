# 协调协议 — OOK Shaped Polar 验证

> 本文件是所有五个 `p` 单元的数值口径唯一裁判。若改变任一公式、字段或判定规则，必须先更新本文件，再重跑受影响单元的 smoke。

## 1. 概率与集合契约

| 名称 | 定义 | 约束 |
| --- | --- | --- |
| `p_target` | `P_X(1)`，OOK 高电平 `1` 的目标概率 | 本 loop 取 `0.5:0.1:0.9`。 |
| `q_bsc` | `min(p_target,1-p_target)` | 本 loop 的高电平偏置下 `q_bsc=1-p_target`。 |
| `h2(q)` | `-q log2(q)-(1-q)log2(1-q)` | `q=0` 或 `1` 时按连续极限处理；本 loop 不取端点。 |
| `S_size` | `ceil(N*(1-h2(q_bsc)))` | `p_target=0.5` 时必须为 0。 |
| `S_set` | BSC(`q_bsc`) 上最可靠的 `S_size` 个极化子信道 | 用 Bhattacharyya 递推；不得由 OOK-AWGN 排序替代。 |
| `I_set` | 当前横轴 SNR 的 GA 口径下、排除 `S_set` 后选出的信息集 | 与 `S_set` 不相交；每个 SNR 点重构。 |
| `F_set` | 剩余集合 | `S∪I∪F={1,…,N}` 且两两不交。 |

本 loop 固定 `N=1024` 与 `K=ceil((N-S_size)/2)`，输出字段 `rate_design='legacy_half_remaining'`，并硬检查 `S_size+K<=N`。

### 构造算法与索引约定

- **BSC**：从 `Z0=2*sqrt(q_bsc*(1-q_bsc))` 递推 `Zminus=2*Z-Z^2`、`Zplus=Z^2` 至长度 N，以最小 Z 为最可靠；索引必须用与 `polar_encoder` 相同的 bit-reversal 映射，并用 N=2/4 手工例检查。
- **GA**：对每个横轴 `snr_db` 调用现有 `GA(sigma_ga,N)`，其中 `sigma_ga=10^(-snr_db/20)`；删除 `S_set` 后，剩余最高 K 个为 `I_set`，其余为 `F_set`。因此每个 BER 点是逐 SNR 自适应构造。

## 2. 编码与统计契约

1. 信息位独立均匀生成；frozen bits 固定为 0，种子和是否固定跨帧必须记录。
2. SC precoder API 必须接收 `(prior_llr,S_set,I_set,F_set,info_bits,frozen_values)`；本帧信息位与冻结值都是已知 decision，仅 `S_set` 待 SC 决定。`L_prior=log((1-p_target)/p_target)`。
3. 组装 `u`：`I_set` 放本帧信息位，`S_set` 放消息条件化 precoder 输出，`F_set` 放冻结 bits；两条不同消息必须验证 shaping 输出或生成轨迹不恒定。
4. 单码字统计固定为 `p_encoded=sum(c==1)/N`。
5. 每个单元必须保存 `sample_id,p_target,q_bsc,p_encoded,S_size,K,seed`；基于独立码字样本计算：

```text
mean_p_encoded = mean(p_encoded)
std_p_encoded  = std(p_encoded)
CI95 = mean_p_encoded ± t_{0.975,n-1} * std_p_encoded/sqrt(n)
target_in_ci = (CI95_low <= p_target <= CI95_high)
```

校准 smoke 使用至少 100 条独立码字；正式校准使用至少 1000 条独立码字和不重复派生 seed，且 `CI95_half_width<=0.01`。对于 `std=0` 或样本数不足以估计 CI 的情况，必须报告“统计不可判定”，不可自动通过。

## 3. OOK-AWGN 与 LLR 契约

- OOK 映射固定 `a=1`，即 `0→0`、`1→1`。
- **legacy spow 归一化**：每条码字 `spow=mean(c.^2)`，`sigma_noise=sqrt(spow/(2*10^(snr_db/10)))`，再令 `y=c+sigma_noise*randn(N,1)`；这固定每帧 `E_s/N_0`，不是固定物理噪声方差模型。
- **GA / SC LLR**：`sigma_ga=10^(-snr_db/20)`；通信译码固定使用原脚本 `L_legacy=(1-2*y)/(2*sigma_ga^2)`。结果必须记录 `sigma_ga`、`spow`、`sigma_noise` 与该缩放关系。物理 `L_phys=(1-2*y)/(2*sigma_noise^2)` 仅作诊断列，不与 `L_legacy` 混用。

## 2026-10-09 修订：S/I/F 构造与独立源熵证据

本项目当前采用的方案固定 $K$ 与 $|S|$：在目标 Bernoulli($p$) 源下估计 $H(U_i|U^{i-1})$，按源条件熵从低到高选择 $S$；移除 $S$ 后，再按通信信道 GA 可靠性选择 $I$ 和 $F$。每帧先固定当前 payload 与 $F=0$，再以 SC 强制译码求出 $S$，使整形位随消息条件化。源条件熵是源模型量，不含信道噪声；GA 是剩余位置上的信道可靠性排序，两者用途不同。

这取代“对单一通信 GA 排序的前缀同时取作 $S$、再取 $I$”作为新实验构造。旧图和结果保留作历史，不再支撑新构造的当前性能结论。有限码长下精确匹配目标 PMF并无保证；冻结 $F=0$、有限源熵估计与当前 SC 构造都会留下残差。

独立源样本验证（构造 seed 9001，评价 seeds 12001/22001/32001，各200个源码字）显示：$p=0.1$ 时，新集合 $S/I/F$ 的平均独立源条件熵约为0.054/0.944/0.942；旧GA分段约为0.459/0.428/0.541。结果见[独立源熵比较图](../../16QAM_Polar/v2/results/20261009_180433_b4b_source_partition_holdout_audit/figures/source_entropy_holdout.png)与逐位置数据。该证据验证集合分工改善，不等于通信性能或硬件收益证明。

$N=1024$、五个 $p$、3 seed×80完整码字的经验联合PMF诊断全部通过预注册门槛：pooled TV单侧95%上界约0.0080–0.0262，逐seed最大上界约0.0146–0.0274（门槛0.05）。$N=256$与$1024$在新条件化方案下也均通过；短码上界范围约0.0148–0.0326，长码约0.0080–0.0262。见[码长PMF/实际符号能量对照图](../../16QAM_Polar/v2/results/20261009_182029_b4b_blocklength_comparison/figures/b4b_blocklength_pmf_energy.png)。两种码长的差异支持有限长度影响残差，但不足以证明渐近收敛或把所有残差单独归因于码长。

当前正式通信性能与整形图重建仍在进行；在正式结果、数值复核和图像审计完成前，不更新收益大小或最佳工作点结论。旧v3 source-MC结果属于独立多流BICM口径，不自动替代本方案验证。

## 2026-10-09 最终构造审计与F19理论差距

固定K与$|S|$后，独立精确源条件熵估计选S，剩余位置逐SNR采用信道GA选I/F，编码端按当前payload与F=0逐帧执行条件化precoding。正确集合下N=64合同测试通过：S/I/F互斥完备、大小正确、GA top-K I在S之外、全零/全一/两种固定seed随机payload均无噪声SC恢复正确，且full-chain导出的`I_by_snr`逐点与独立重算一致。旧构造入口保持兼容；`run_single`旧路径本轮smoke完成。

F19 code-only正式图：`16QAM_Polar/v2/results/20261009_202540_phaseA_codeonly_gap_analysis/figures/`。普通SC接收端不额外加源先验，刻意固定此口径隔离集合构造；N1024、5次重复中，SNR标签3 dB仿真/理论BER比值p=.5/.4/.3/.2/.1分别约131/66.6/22.9/9.78/1.37，3.25 dB分别约91.8/129/33.4/11.2/1.52。故当前理论估计明显低估p≥.2的仿真BER，不能直接作为绝对BER约束或优化预测。单载波实际Es/N0标签口径与该code-only低SNR网格并非同一横轴定义，应分别读README。

边界：本次完成的是新构造一致性和已登记数据下图重建；尚未完成匹配先验/源条件可靠性模型。F19不证明渐近收敛，也不支持将差距单归因于冻结位。


## 2026-10-24 S机制对照追加

原源熵选S、余位GA选I/F与消息条件化整形保持不变。新问题出在“取消S并冻结0”的对照：它可能固定输出位，不能当作均匀基线。保留原S/I/F并在S放独立公平辅助位，当前21组生成矩阵审计均支持均匀输出；接收端仍判决I与S，只统计I。

供体S取自另一独立消息，可保留S向量内部统计并打破当前消息配合，不预设均匀PMF。源条件低熵不等于跨消息的S边缘熵低。以上不推翻原PMF证据，也不证明P2预测/通信优势；正式预算未批准。见[当前结论](../多载波OFDM瑞利信道-loop/机制对照与P2/等功率机制与P2当前结论.md)。
