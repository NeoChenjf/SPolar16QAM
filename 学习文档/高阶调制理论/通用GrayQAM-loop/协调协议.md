# 协调协议 — 通用 GrayQAM

> 本文件是 v3 通用 Cartesian Gray QAM shaped-polar 的接口与数值口径裁判。实现与本文冲突时，先更新本文并回归已完成单元，不得让代码形成第二套隐含协议。

## 1. 顶层函数契约

```matlab
result = sim_shaped_polar_gray_qam(M, shaping_spec, snr_dB, cfg)
```

### 输入

| 参数 | 约束 | 含义 |
| --- | --- | --- |
| `M` | 标量，首版仅 `8/16/32/64` | QAM 星座点数。 |
| `shaping_spec` | 结构体 | 目标生成方式、每轴 latent `p`、relation 与 solver 配置。 |
| `snr_dB` | 有限实向量 | 横轴 SNR；具体口径由 `cfg.snr_mode` 指定。 |
| `cfg` | 结构体 | `N`、帧数、seed、SC设置、噪声/缩放/输出设置。 |

### 输出最小字段

```text
M, m, M_I, M_Q, m_I, m_Q
constellation, labels, uniform_scale
axis_I, axis_Q, relation_I, relation_Q
target_psym, model_psym, empirical_psym
kl_target_model, tv_target_model, pmf_validation
BER, BLER, BER_per_bit, BLER_per_bit, errors, frames
K, S_size, F_size, R_code, R_bpcu, Goodput, BLER_joint
rf_energy_proxy_model, rf_energy_proxy_empirical, lambda
snr_dB, snr_mode, cfg, seed, result_dir
```

## 2. Cartesian 分解

令 `m=log2(M)`：

```text
m_I = ceil(m/2),   m_Q = floor(m/2)
M_I = 2^m_I,       M_Q = 2^m_Q
```

I 轴取较高阶 PAM。标签总顺序固定为 `[I-axis bits, Q-axis bits]`，每轴按 canonical Gray integer 的 MSB→LSB排列。若以后改变顺序，必须版本化 protocol 并回归全部单元。

## 3. Gray-PAM 与缩放

每轴未缩放电平为：

```text
-(L-1), -(L-3), ..., -1, +1, ..., +(L-1),  L=M_axis
```

采用 canonical reflected Gray 标签：未缩放电平从负到正编号 `n=0,...,L-1`，Gray integer固定为 `g=bitxor(n,floor(n/2))`，标签按 `g` 的 MSB→LSB。生成器必须输出电平—标签表，不允许依赖固定索引猜符号位/幅度位。相邻一维电平的 Hamming distance 必须为 1。v3 不允许静默轴交换、bit置换或取反；对 v2 回归时必须显式保存 canonicalization 双射。

QAM 原始点为 `x=a_I+j*a_Q`。固定缩放：

```text
uniform_scale = sqrt(mean_uniform(|x|^2))
x_scaled = x / uniform_scale
```

该 scale 对同一个 `M` 的所有 shaping setting 固定，不按 `model_psym` 重算。

## 4. 概率与关系表示

每轴先有列向量 latent bits `z∈GF(2)^k`，其分量边缘为 `P(z_k=1)=p_k`；再通过 GF(2) 可逆矩阵生成 canonical Gray label列向量 `b`：

```text
b = T*z mod 2         % 固定列向量约定
relation=[]           % 规范化为 identity
relation='auto'       % 解析为已枚举/优化、登记并冻结的轴关系
relation=T            % 显式二进制可逆矩阵/等价变换描述
```

`T` 必须方阵且在 GF(2) 可逆；接收端按 `z=T^{-1}b mod 2` 为每个星座点生成 latent labels。为了让 relation 真正按 PAM阶数复用，`'auto'` 搜索使用轴自身均匀能量归一化 `a_axis_scaled=a/sqrt(E_axis,uniform)`，首版设计网格固定为轴归一化 `lambda_axis=[-0.5,-0.25,0,0.25,0.5]`。对该轴阶数的全部 GF(2) 可逆矩阵枚举，并在 `p_i∈[1e-4,1-1e-4]` 内为每个设计点联合优化 `p`。裁判先最小化网格平均 KL，再以最坏点KL、矩阵字典序打破平局；矩阵一旦选定即按 PAM阶数冻结，不能因其嵌入8/16/32/64QAM的总缩放不同而换矩阵。实际QAM测试点的 `p` 仍按完整QAM目标重新求解。搜索得到的 `T_3` 称 optimized GF(2) relation，不能称论文 polar relation。

当前energy-lambda实现使用版本化显式registry：PAM2为唯一单位关系；PAM4固定`T=[1 1;0 1]`，其第二latent位区分Gray标签的内/外层、第一位保持符号对称，因此可精确表达对称energy-lambda族；PAM8使用已冻结的optimized GF(2)关系。PAM4显式关系不称为auto搜索唯一解；registry变更必须版本化并回归PMF、环回、LLR及BER。

模型轴 PMF必须枚举所有 latent bit 组合计算，不得把相关 label bits 又按边缘概率相乘。QAM 模型 PMF在本 loop 中采用轴独立组合：

```text
P_X(a_I+j*a_Q) = P_I(a_I) * P_Q(a_Q)
```

## 5. shaping_spec 规范

允许三个入口，最终都必须输出规范化的 `p_I/p_Q/relation_I/relation_Q/model_psym`：

```text
source='energy_lambda'  : target P_X(x) ∝ exp(lambda*|x_scaled|^2)
source='axis_pmf'       : 用户提供目标 P_I、P_Q
source='latent_p'       : 用户直接提供 p_I、p_Q
```

- `lambda=0` 必须退化为均匀目标。lambda作用于固定均匀缩放后的无量纲能量；不同 M仍须同时报告目标能量，不能仅凭相同 lambda宣称同等 shaping强度。
- `axis_pmf` 必须非负、有限、归一且与轴电平等长。
- `latent_p` 每项必须在开区间 `(0,1)`；若未来允许 0/1，须新增确定性边界协议。
- 从 target 解 `p` 时必须保存优化算法、边界、初值/多起点、退出状态、目标 KL 与最终 PMF。
- KL 定义固定为 `D_KL(P_target || P_model)`；零概率采用明确的 log-domain 规则。
- `source='latent_p'` 是按构造给定模型：固定 `target_psym=model_psym`、`kl_target_model=0`、`tv_target_model=0`、`match_status='by-construction'`，仍需执行经验PMF门禁。

默认 target→model 判据（可在运行前预登记收紧，运行后不得追改）：`exact` 为 `KL≤1e-10` 且 `TV≤1e-8`；`approximate-pass` 为 `KL≤2e-2 nat` 且 `TV≤5e-2`；否则 `fail`。无法精确匹配不是编码错误，但 `fail` 不得勾选 PMF门禁；不得写“任意 PMF 精确实现”。

## 6. Multi-stream Polar 与 latent demapper 契约

- 每个 latent bit-level 对应一条长度 `N` 的 polar stream，总流数为 `m`，每帧发送 `N` 个 QAM符号。这是 v3 multi-stream BICM extension，不是论文单整体 polar graph 的有限长等价实现。
- 每个 latent stream 的 `S/I/F`、`K`、先验和构造证据独立保存，且 `|S_b|+K_b+|F_b|=N`。
- 同时定义 `R_code=sum(K_b)/(mN)` 与 `R_bpcu=sum(K_b)/N=m*R_code`。
- SC 同时用于 shaping precoder 和通信 decoder。
- **发送端条件化顺序固定**：每帧先把真实payload写入 `u(I)`，把约定冻结值写入 `u(F)`，再把这些 decision作为SC precoder的已知约束，只求 `u(S)`。禁止先脱离本帧payload求shaping bits、随后覆盖 `u(I)`；同一seed改变payload时，`u(S)`必须允许随之变化。
- **接收端集合角色固定**：`F` 是唯一已知冻结集，`A=I∪S` 全部作为未知位参与通信SC解码；解码后仅提取 `u(I)` 作为payload，`u(S)`丢弃且不计入payload码率、BER或Goodput。
- 对每个星座点先计算 `z(x)=T^{-1}b(x)`，demapper直接按 `z_k(x)=0/1` 分组做完整星座LSE，输出 latent bit metric；禁止先算单独 `L(b_j|y)` 再用复制、符号翻转或普通实数矩阵逆变换冒充 latent LLR。
- 通信 SC decoder使用已含 `model_psym` 的 latent posterior metric时，不得再次叠加 `log((1-p_k)/p_k)`；该 prior仅用于发送端 shaping precoder。若实现改用纯 likelihood metric，必须在 protocol中显式版本化并证明 prior只计一次。
- 无噪声环回必须覆盖非零随机消息、所有 stream、至少两个 seed 和全部 `M`。

`S` 的严格构造（BSC）与 `I/F` 的目标 latent bit-channel可靠性构造属于 build 的方法实现，但必须分别留痕。对 `p_k>0.5`，BSC可靠性构造使用 `q_k=min(p_k,1-p_k)` 的对称信道，发送端 prior仍使用带符号的 `log((1-p_k)/p_k)`；必须用 `p` 与 `1-p` 对称测试证明方向正确。若首版用近似 GA，结果必须标为近似，不能写成论文严格 Monte Carlo 构造。

## 7. MAP/LSE demapper

对每个 latent bit `k`，令完整 QAM星座的 latent label由各轴 `T^{-1}b` 得到：

```text
L_k(y) = log Σ_{x:z_k(x)=0} P_X(x) exp(-|y-x|²/(2σ²))
       - log Σ_{x:z_k(x)=1} P_X(x) exp(-|y-x|²/(2σ²))
```

- 使用完整 `model_psym`，不是独立 bit prior 乘积近似。
- 使用稳定 log-sum-exp；输出顺序严格为 `[I latent bits,Q latent bits]`。
- `sigma` 是每实维噪声标准差。
- 无噪声测试可用有限极小 sigma 或解析 hard-label 辅助，不得产生 NaN/Inf 后静默裁剪。

## 8. SNR 与能量口径

```text
fixed_n0   : 噪声由固定的均匀星座参考功率决定；用于物理能量增益比较。
fixed_esn0 : 噪声随当前 shaped 平均 Es 缩放；用于等 Es/N0 编码比较。
```

固定缩放后均匀参考能量 `E_ref=1`，每实维噪声方差固定为：

```text
sigma2_fixed_n0   = 1 / (2*10^(SNR_dB/10))
sigma2_fixed_esn0 = E_model / (2*10^(SNR_dB/10))
```

每张图和结果表必须携带 `snr_mode` 和公式版本。能量单调验收固定使用 `fixed_n0` 与同一个 `uniform_scale`。

理论平均发射 RF 能量代理量：

```text
E_model = Σ_x model_psym(x)*|x_scaled|^2
```

经验代理量必须由实际发送符号求均值，并按独立帧统计与 `E_model` 对照。它不是非线性整流器的收获直流能量；本 loop不得简称“收获能量”。

## 9. 五项验收协议

### A. 星座/标签

- 点数、唯一性、轴分解、标签唯一性通过；
- 每轴相邻 Gray Hamming distance 为 1；
- 均匀 PMF 下平均缩放能量为 1（数值误差阈值 `1e-12`，若 Octave 数值限制需在 README 解释）。

### B. PMF

- `target/model/empirical` 三份 PMF全部保存；
- `target→model` 保存 KL 与 TV，不把近似误差伪装成采样误差；
- `empirical→model` 以独立帧为统计簇，保存每帧 PMF。cluster bootstrap每次重采样完整帧，计算 `TV(mean(P_frame*),P_model)`；正式门禁的单侧95%上置信界须 `≤0.05`。同时保存每点平均偏差，不把码字内部 `N` 个位置当 iid Wilson样本。smoke可用上界 `0.10`，但不能完成正式 B 门禁。
- target→model 的 exact/approximate/fail 使用 §5 数值阈值；经验偏差与 finite-length shaping loss分开报告。

### C. 无噪声环回

- 全部信息位零错误；
- 不允许只测全零消息；
- 检查每个 stream 与汇总 BER，relation 前后标签可逆。
- 专项检查消息条件化：固定其他条件、改变至少一个payload bit，重新运行precoder；不得复用旧 `u(S)`。接收端断言冻结掩码仅含 `F`，活动集严格为 `I∪S`，最终只比较 `I`。

### D. AWGN BER

- 先粗扫，再定位 BER约 `1e-4~1e-1` 瀑布区；
- 保存每点 errors/frames/seed；全零错误点只表示采样上限；
- 正式 D 门禁至少有 2 个点落在 `1e-4~1e-1`，每个有效点累计不少于100个信息位错误；达到预登记帧上限仍不足则标 `insufficient`，不得勾选。smoke只作方向检查，full曲线需用户授权。

### E. 能量单调

- 使用至少三个有序点 `0=lambda_0<lambda_1<lambda_2`，运行前选到模型能量差非零且 PMF未进入数值退化区；
- 模型能量必须严格递增。经验能量用相同 seed的独立帧做配对差，两个相邻差值的95% cluster-bootstrap下置信界均须 `>0`；否则标 `insufficient/fail`，不能用点估计勾选；
- 报告各点 `R_code/R_bpcu`，不得把码率下降误判为编码失败。

### F. BLER 与 Goodput口径

```text
BLER_joint = P(任一 payload stream 的信息块出错)
Goodput_bpcu = R_bpcu * (1-BLER_joint)
```

每流 BER/BLER仍需保存。主 Goodput使用 joint BLER；若另报 `R_bpcu*(1-BER_weighted)`，必须命名为 BER-proxy，不得与主口径混用。
