# 通用 Gray QAM 数能同传极化码：需求澄清

> 状态：已由用户逐项确认（2026-08-26）  
> 后续设计目录：`学习文档/高阶调制理论/通用GrayQAM-loop/`

## 1. 目标

在 `16QAM_Polar/v3/` 建立一个超越 v2 固定四路结构的通用单载波仿真核心。调制阶数 `M` 是显式输入；同一套接口完成 Cartesian Gray QAM 下的 shaped-polar 编码、调制、AWGN、先验感知软解调、SC 译码与 BER/BLER/Goodput/能量统计。

v3 明确采用 **multi-stream BICM extension**：每个 QAM latent bit-level 对应一条长度 `N` 的 shaped-polar stream，一个帧发送 `N` 个 QAM 符号。它受论文的“biased polar codeword + 跨层线性关系”启发，但不声称与论文“单个整体 polar codeword 分块后继续极化”的有限长码图等价。严格论文复现不是本 loop 的验收目标。

目标接口概念为：

```matlab
result = sim_shaped_polar_gray_qam(M, shaping_spec, snr_dB, cfg)
```

## 2. 工作单元

| 单元 | Cartesian 分解 | 作用 |
| --- | --- | --- |
| 8QAM | 4-PAM × 2-PAM | 最小矩形 QAM；一轴可做幅度整形。 |
| 16QAM | 4-PAM × 4-PAM | 与 v2 共同正确口径做回归；两轴各一个幅度层。 |
| 32QAM | 8-PAM × 4-PAM | 非对称 I/Q bit-level 数量；检验通用轴接口。 |
| 64QAM | 8-PAM × 8-PAM | 两轴多幅度层及相关结构。 |

这里的 8/32QAM 均指矩形 Cartesian QAM，不泛指 cross-QAM。

## 3. 范围

### 在范围内

- 单载波复 AWGN；Cartesian Gray QAM；`M=[8,16,32,64]`。
- I/Q 两个 Gray-PAM 轴分别构造，再组合为 QAM。
- SC precoder 与 SC communication decoder；不引入列表译码。
- 关系结构与概率参数统一表示：每轴含 latent bit 概率向量 `p` 与 GF(2) 关系 `relation`。
- `relation='auto'` 使用经枚举/优化并冻结的可逆 GF(2) 关系；`relation=[]` 等价于单位关系，仅作为结构退化形式，不另设 legacy 模式。只有被论文明确给出并验证的矩阵才允许标为 `paper_*`，8-PAM 的任意搜索矩阵不得称为论文 polar relation。
- 目标分布既可由能量倾斜参数 `lambda` 生成，也可由轴 PMF 或底层 `p` 给出；所有路径最终进入同一编码链。
- 完整符号先验 MAP/LSE LLR；BER、BLER、Goodput、实际 PMF、KL 误差、平均能量和 bit-level 统计。
- 支持并明确区分 `fixed_n0` 与 `fixed_esn0`，不得混用结论。

### 不在范围内

- OFDM、Rayleigh、多径、信道估计与均衡。
- SCL、CRC、HARQ。
- cross-QAM、APSK、非 Cartesian 星座、非 Gray 标签。
- 任意 2D 联合 PMF 的精确 distribution matcher。
- 自动运行长 Monte Carlo；full run 仍须用户授权。

## 4. 已确认的理论与架构决策

1. v2 的 `[0.5,p,0.5,p]` 只在标准 Gray 16QAM 中恰好对应两个符号位保持均匀、两个幅度位受控；新系统不得硬编码 bit 位置。
2. Gray 标签角色必须从实际 I/Q PAM 几何与标签表推导，并允许 bit 置换/取反导致的参数方向变化。
3. 对固定轴阶数，默认先在预登记 `lambda` 设计网格上选定一个 relation 并冻结；改变能量偏好只重新求 latent `p_i`。无相关需求时 `relation=[]`。
4. 固定数量的 `p_i` 和固定关系只能表达一族联合 PMF；无法精确表达时必须报告最优 KL 误差，不得宣称任意 PMF 精确可达。
5. v2 保持不动，只作为 16QAM 星座、标签、均匀 LLR和无噪声链路的外部参考；新系统不实现 `legacy_v2` 正式模式。回归时先登记 v2 标签到 v3 canonical 标签的置换/取反双射。
6. 星座缩放以该 `M` 的均匀 Cartesian 星座平均能量为固定基准，不随 shaped PMF 重新归一化，否则能量增益会被定义性消除。

## 5. 每个单元的验收标准

每个 `M` 必须同时通过：

1. 星座点、Cartesian Gray 标签、邻接和固定缩放检查；
2. 目标 PMF、模型 PMF、经验 PMF检查，并保存 KL/统计误差；
3. 无噪声 shaped-polar 编解码环回零信息位错误；
4. AWGN 下存在可解释的 BER 瀑布区，且保存错误数/帧数；
5. 在相同固定归一化与 `fixed_n0` 下，正 `lambda` 增大时平均发射 RF 能量代理量单调不减。

## 6. 终止条件与交接

8/16/32/64QAM 全部五项验收通过后，再通过“一份配置仅改变 `M` 即依次运行四个单元”的跨阶数接口测试。用户审核结果图、经验 PMF、KL 误差和 BER 曲线并明确接受后，loop 才能结束。

build agent 从本目录的 `loop-design → loop-protocol → loop-board → loop-issues` 顺序接手。看板是进度真相源，protocol 是数值与接口裁判。
