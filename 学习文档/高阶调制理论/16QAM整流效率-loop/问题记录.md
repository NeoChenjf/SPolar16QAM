# 问题记录

## 1. 整流模型被误设为当前阶段硬门禁 🟢

用户明确当前研究意图为能量强度，并选择真实发送符号代理、p=0.5为1。决定取消模型硬门禁，材料保留开题原文并说明代理定义。需求已解决；正式材料回填仍待Unit 6，不能提前改完成状态。

## 2. SNR标签与复噪声总方差存在3.01 dB换算 🟢

代码用sigma_noise*(randn+j*randn)，复总方差为2*sigma_noise²。保留历史fixed_esn0实现，同时保存输入标签及实际Es/N0；独立N0断言和正式图注均已验证。实际Es/N0=标签−3.0103 dB。

## 3. 经验发送能量不应预设为SNR无关 🟢

此前访谈中“发送能量与SNR无关”的表述过强：GA排序和集合构造使用SNR，随机流也随网格推进。正式实验已按p/seed/SNR逐点统计并配对归一化，单位能量图按13个SNR分面；不把解析式当经验真值。

## 4. 三个seed的置信区间和排序能力有限 🟡

采用自由度2的t区间而非旧脚本1.96系数；均值Pareto和等权折中均为描述性结果。n=3及固定300帧由用户确认，公式与图注已验证；有限seed导致的排序不确定性仍是解释边界，不自动扩大实验。

Windows MATLAB R2020b及通信工具箱已核验，项目根包装脚本、绘图和三格式输出均通过；环境文档已补充当前入口。正式运行耗时1366秒。

## 6. 随机流兼容与断点恢复 🟢

保持每个p/seed的完整SNR向量调度；采集开关与含rand回调均不改变通信RNG。缺块恢复、精确行对比、配置不匹配拒绝和去重均已通过专项测试。

## 7. 缩放后的目标能量增大不等于系统能效提高 🟢
