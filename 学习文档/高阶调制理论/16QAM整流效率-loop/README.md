# 16QAM BER—归一化发送能量强度权衡

> 2026-09-15｜状态：正式实验、数值审计和四图视觉检查通过；待回填中期DOCX/PPT。
> 本文是本工作包唯一资料入口。目录沿用最初指定名称；实际指标已按用户后续澄清调整。

本工作包研究不同概率整形方案的通信表现与发送能量强度。能量由真实发送符号的均方值计算，在同一 seed、SNR 下以 p=0.5 为1单位；所有方案保持相同星座缩放。

用户明确解释：开题报告中的“整流效率”原意是能量强度。本阶段按用户确认的代理评价口径验收，非线性整流模型不再作为硬性完成标准。中期材料保留开题任务原文，并注明本阶段使用归一化发送能量强度，非 RF–DC 转换效率；不声称原报告物理术语与当前指标严格等价。

## 2026-10-09 整形构造修订及正式图重建状态

本环原有16QAM通信—能量图使用旧版GA分段与固定整形位，不能作为新构造的正式比较。新构造保持各 $p$ 的 $K$ 与 $|S|$ 计数，按源条件熵选 $S$，在剩余位置按通信 GA 排序选 $I/F$，并逐帧按payload重新求 $S$。目标PMF、模型PMF与经验PMF分开保存；实际符号能量从发射码字统计，不由目标边缘概率代替。

本轮源熵独立评价、N=1024正式PMF门禁和N=256/1024能量/PMF比较路径见[整形理论更新与仿真图重建清单](../../shaped_polar验证loop/理论更新与图重建/整形理论更新与仿真图重建清单.md)。当前PMF门禁通过，但能量/通信正式结果仍在本轮运行中；原等功率与RF–DC转换结论均未由本轮数据回答。阶段A展示图待基于新正式数据重绘后再更新。

14 dB标签下，p从0.5降到0.1时归一RF能量由1.000升至1.615，但BER由0.381升至0.315，Goodput由0.310降至0.251；20 dB标签下BER依次约为0.0134、0.0302、0.0544、0.0802、0.0996。观察到成形提高能量代理量的同时牺牲通信性能；这不是等发射功率比较，也未证明直流收益。三seed t区间仅是有限重复的描述区间。
