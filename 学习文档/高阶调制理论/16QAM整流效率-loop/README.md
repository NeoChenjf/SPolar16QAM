# 16QAM BER—归一化发送能量强度权衡

> 2026-09-15｜状态：正式实验、数值审计和四图视觉检查通过；待回填中期DOCX/PPT。
> 本文是本工作包唯一资料入口。目录沿用最初指定名称；实际指标已按用户后续澄清调整。

本工作包研究不同概率整形方案的通信表现与发送能量强度。能量由真实发送符号的均方值计算，在同一 seed、SNR 下以 p=0.5 为1单位；所有方案保持相同星座缩放。

用户明确解释：开题报告中的“整流效率”原意是能量强度。本阶段按用户确认的代理评价口径验收，非线性整流模型不再作为硬性完成标准。中期材料保留开题任务原文，并注明本阶段使用归一化发送能量强度，非 RF–DC 转换效率；不声称原报告物理术语与当前指标严格等价。
