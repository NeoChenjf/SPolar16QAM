# Shaped Polar 的高阶调制方法：论文机制与 16QAM 落地

> 依据：`参考文献Polar/Shaped_Polar_Codes_for_Higher_Order_Modulation.pdf`。  
> 本文把论文原始构造与本项目的方形 16QAM 方案明确分开；未在本轮运行新仿真。

## 1. 先给结论

论文所称的“任意高阶调制”，严格说是任意 `2^m`-ASK（一维实星座），并不是直接给出了方形 16QAM 的编码器。它的关键不只是让每个比特层取不同的 0/1 概率，而是：

1. 每个被整形的极化码字先由 shaped-polar precoder 产生非均匀比特；
2. 对多个比特层的码字做一个特定的线性 XOR 变换，重排联合概率质量，并在一般参数下形成跨层相关性；
3. 将变换后的比特按 Gray 标签映射到 ASK 星座；
4. 接收端在符号度量中加入非均匀符号先验，再做常规极化译码。

直觉上，单独掷两枚“偏硬币”只能控制每一位出现 0/1 的比例；论文的XOR组合会重排它们落到Gray标签组合上的概率质量，从而把更多概率集中到目标幅度点。在特殊参数下，变换后的标签位仍可能独立，因此不能把“做了XOR”本身等同于“必然相关”。

对本项目，最自然的严格延伸是：把方形 16QAM 视为两个正交且独立的 4-ASK 轴（I 轴、Q 轴），在每一轴上采用论文的 `m=2` 构造，然后组合成 16QAM。它是对论文方法的可解释扩展；但“论文直接验证了 16QAM”这一说法不成立。

## 2. 论文的二元基础模块

对长度为 `N` 的极化码字 `c`，希望其比特满足 `P(c=1)=p`。论文使用一组 shaping 位置 `S`，其规模近似为：

```text
|S| ≈ N [1 - h2(p)]
```

其中 `h2(p)` 是二元熵。发送端把 `S` 位视为一个虚拟 BSC 的信息位，在先验

```text
L_prior = ln((1-p)/p)
```

下运行极化 SC/SCL decoder，得到使编码输出趋近目标概率 `p` 的 shaping bits。真实信息放在 `I`，其余放在冻结集 `F`。

论文的严格两阶段构造是：

```text
BSC(p) 的可靠位  →  S
目标调制-AWGN 比特信道的可靠位（排除 S）  →  I
其余  →  F
```

因此，`S` 的职责是“制造分布”，`I` 的职责才是“承载通信信息”。这与我们已验证的 OOK legacy 链路在思想上相通，但 legacy 中用同一 GA 排序一次性划分 `S/I/F`，不是论文的严格两阶段实现。

## 3. 4-ASK：最重要、也最适合接到 16QAM 的特例

令两条 shaped-polar 码字为 `c1,c2`，先进行：

```text
c1' = c1 xor c2
c2' = c2
```

然后用 `(c1', c2')` 的 Gray 标签映射至 `{-3,-1,+1,+3}`。按论文的标签表，概率为：

| 幅度点 `x` | `(b1,b2)` | 概率 |
| ---: | :---: | :--- |
| `-3` | `(0,1)` | `p1 p2` |
| `-1` | `(0,0)` | `(1-p1)(1-p2)` |
| `+1` | `(1,0)` | `p1(1-p2)` |
| `+3` | `(1,1)` | `(1-p1)p2` |

取 `p1=0.5`，则正负号等概率，而 `p2<0.5` 会使 `±1` 比 `±3` 更常出现：

```text
P(±1) = (1-p2)/2,    P(±3) = p2/2.
```

如果目标为 Maxwell–Boltzmann（MB）分布 `P_X(x) ∝ exp(-νx²)`，则 4-ASK 可直接得到：

```text
p2 = 1 / [1 + exp(8ν)].
```

这说明 4-ASK 情况下，真正承担幅度整形的是第二条码字；第一条保持均匀，承担符号正负号。对于方形 16QAM，这个角色分离尤其清晰。

## 4. 一般 `2^m`-ASK：先组合码字，再映射比特层

论文将一个长度 `N` 的二进制极化码字分为 `m` 个长度 `N/m` 的块，分别由短极化 precoder 产生 `c1,...,cm`。随后对块做附加极化变换得到 `c1',...,cm'`，再将第 `i` 组填入 ASK 标签的第 `i` 比特层。

论文给出的 16-ASK（`m=4`）例子是：

```text
c1' = c1 xor c2 xor c3 xor c4
c2' = c2 xor c4
c3' = c3 xor c4
c4' = c4
```

为了实现对称 MB 分布，可固定 `p1=p2=0.5`，只数值求解 `p3,p4`；论文以最小化目标 MB 分布与构造分布的 KL 距离来选这两个参数。它还给出约束 `p4≤0.5`、`p2(=0.5)·p3+p4≤1`。

注意这里的 16-ASK 是 16 个一维幅度点，不等于本项目的方形 16QAM；不能把该 XOR 矩阵不加改造地套到四个 QAM 标签位上。

## 5. 接收机与可靠性构造

### 5.1 非均匀 demapper

接收端应使用符号先验：

```text
L_j(y) = log [ Σ_{x:b_j(x)=0} P_X(x) exp(-|y-x|²/(2σ²))
                / Σ_{x:b_j(x)=1} P_X(x) exp(-|y-x|²/(2σ²)) ].
```

这不是简单给每个 bit LLR 加常数，而是按完整星座的联合符号先验 `P_X(x)` 汇总。论文随后将这些 LLR 送入普通极化 decoder；整形先验只在发送端 precoder 生成 shaping bits 时使用。

### 5.2 真实调制信道的 `I` 集

论文对目标的非均匀 4/16-ASK + AWGN 信道，采用蒙特卡洛方法估计 bit-channel 可靠性，再从非 `S` 位中选出 `I`。这比“仅在某典型 SNR 做一次 GA”更接近实际 bit-metric 信道，但计算成本更高。

落到当前项目时应把以下两件事分开：

- **分布构造**：BSC(p) 决定 `S`；
- **通信可靠性**：由该 SNR 下、带真实 `P_X` 先验的 16QAM demapper 产生的比特信道决定 `I/F`。

## 6. 如何把论文方法落到方形 16QAM

标准方形 16QAM 可拆为两个正交的 4-PAM/4-ASK 轴：

```text
P_{X_I,X_Q}(a_I,a_Q) = P_A(a_I) P_A(a_Q),   a_I,a_Q ∈ {-3,-1,+1,+3}.
```

推荐的论文一致路线是：

```text
I 轴：一套 4-ASK shaped polar（符号位均匀 + 幅度位整形）
Q 轴：另一套相同且独立的 4-ASK shaped polar
                 ↓
组合为 16QAM 符号，并令 P_16QAM = P_I × P_Q
                 ↓
16QAM MAP demapper 使用该 16 点联合先验
```

若 I/Q 两轴采用同一 `p2`，低能量内点的概率会自然最高，四个角点的概率最低；这就是矩形 MB 型 16QAM 整形的核心形状。若希望强调能量传输，也可允许 I/Q 使用不同幅度概率，但那是本项目的扩展设计，不是论文原始对称 MB 方案。

## 7. 与当前 v2 实现的差异

当前 [`sim_shaped_polar_16qam.m`](../../16QAM_Polar/v2/core/sim_shaped_polar_16qam.m) 的链路是四条独立极化码字，直接经 [`parallel_to_serial_bits.m`](../../16QAM_Polar/v2/modulation/parallel_to_serial_bits.m) 送入 MATLAB Gray 16QAM。它已有 [`llr_16qam_gray_LSE_prior.m`](../../16QAM_Polar/v2/modulation/llr_16qam_gray_LSE_prior.m) 这个“完整 16 点符号先验”LLR 工具，但主仿真当前调用的是 `qamdemod` 的 LLR，且未实现论文的跨层 XOR 变换。

所以当前 v2 可以称为：

```text
四路独立二元 shaped-polar 驱动的 16QAM 概率偏置仿真。
```

尚不宜称为：

```text
严格复现论文的高阶调制 shaped-polar 编码器。
```

这不是说当前链路没有价值；它适合研究 BER / Goodput / 能量的工程权衡。只是若下一阶段的目标是“论文一致性”，要新增的是**4-ASK 轴内的 c→c' 组合和匹配联合符号先验**，而不是继续只调整四路的边缘 `p`。

## 8. 推荐的设计顺序

1. 固定 4-ASK 单轴：实现 `c1'=c1 xor c2, c2'=c2`，并以 `p1=0.5`、扫描 `p2≤0.5` 验证实际幅度分布；
2. 在单轴验证 MAP demapper 的 `P_A(a)` 先验及 `I/F` 的目标信道可靠性构造；
3. 复制两套独立单轴链路并组合成 16QAM，验证 `P_{I,Q}=P_I P_Q`、平均符号能量和 LLR 标签顺序；
4. 再与现有“四路独立”v2 链路做同码率、同 `E_s/N_0`、同 SC decoder 的对照；
5. 最后才考虑非对称 I/Q 整形、能量导向分布，以及 BSC+GA / Monte-Carlo 构造精度的比较。

这条顺序把“先复现论文机制”与“再探索能量通信联合优化”隔离开，任何差异都更容易定位。

## 9. 当前待确认的研究选择

后续讨论已确认从 16QAM 特例推广到单载波 Cartesian Gray QAM。首轮调制单元为 8/16/32/64QAM，代码计划放入 `16QAM_Polar/v3/`；I/Q 两轴分别使用 Gray-PAM、latent 概率与可选 GF(2) relation构造，再组合完整符号先验和 MAP/LSE LLR。

详细范围、接口、验证与进度以 [`通用GrayQAM-loop`](通用GrayQAM-loop/loop设计.md) 为准。该设计明确：固定 relation 与有限 `p_i` 只能表达一族联合 PMF，无法精确时必须报告 KL/TV；Cartesian 8/32QAM不代表任意 cross-QAM。

还需区分论文原结构与v3工程扩展：论文描述单个整体polar codeword分组并继续极化；v3计划让每个latent bit-level使用一条长度N的shaped-polar stream，再用可逆GF(2)关系映射到canonical Gray labels。v3属于multi-stream BICM extension，不宣称与论文有限长polar graph等价。接收端将按 `z=T^{-1}b` 为星座点生成latent labels，直接计算完整符号先验的latent MAP/LSE metric，而不是从独立Gray label LLR错误地逆推XOR。
