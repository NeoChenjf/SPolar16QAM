固定16QAM、64子载波、CP16、三组N1024、原LLR/SC。主SNR网格为20/24/28/32/36/40 dB，覆盖低SNR失败区与瀑布区；高SNR零错误保留分母及上界。三个预留组合仍为(.3,.1,.5)、(.3,.5,.1)、(.5,.1,.3)。

| 阶段 | 配置/样本 | 发送帧数 |
|---|---|---:|
| OFDM功率校准 | 29配置×6 SNR×3 seed×80帧 | 41760 |
| OFDM独立功率验证 | 同预算；seed8201/8202/8203 | 41760 |
| OFDM正式PMF | 同预算；seed8701/8702/8703，2000次码字簇bootstrap | 41760 |
| 模型校准 | 17已见配置×6 SNR×10信道×20帧，seed8401 | 20400 |
| 独立已见策略测试 | 17配置×6 SNR×30信道×50帧，seed8501 | 153000 |
| 独立未见组合测试 | 12配置×6 SNR×30信道×50帧，seed8601 | 108000 |
| 真实前序位诊断 | 17配置×3 SNR×3信道×2帧，仅诊断 | 306 |
| 单载波功率/PMF与代表点 | p=.5/.3/.1；16/18/20 dB，校准/验证/PMF各3×80，评价100帧 | 7380 |

合计23个注册job、414366发送帧。29配置来自5个已见策略的17配置和3个未见组合的12配置；p=.5等价项去重。纯能量策略只保留原P1边界参照。

按实测分类型耗时，点估计18.8小时；考虑负载和I/O，建议预留23—30小时。逐job预算和源码哈希见[budget.csv](../../../16QAM_Polar/v2/results/20261024_235300_p2_budget_proposal/budget.csv)、[冻结协议提案](../../../16QAM_Polar/v2/results/20261024_235300_p2_budget_proposal/protocol_proposal.json)。

该预算只覆盖首轮80帧校准。若任一正式功率或必需PMF门禁失败，停止依赖实验，定位后再提交扩大样本预算；不自动消耗160/320/640帧长跑。软件已预留新验证seed，不能复用旧验证集反复调系数。无足够误码计数时评价为证据不足。

## 运行依赖

1. 用户确认具体协议及预算后，才创建绑定协议SHA256的真实批准记录。现有approval_request.json的approved=false，不能启动正式job。
2. 用run_p2_registered_job执行功率校准job，p2_freeze_power冻结尺度；再执行独立功率验证及PMF。
3. p2_audit_acceptance生成带原始验收表和哈希的门禁文件；random S按均匀目标验收，shaped按整形目标验收。donor按独立分布模型诊断，不将其改名均匀，也不放宽原0.05门槛。
4. 门禁通过后执行model_calibration，p2_freeze_model冻结两个全局参数及训练功率哈希。pilot模型不能升级为正式模型。
5. 更新模型绑定的门禁文件，执行独立test_seen与test_unseen；测试结果不参与调参。单载波使用自身独立功率和PMF门禁。
6. 运行分析，按信道簇做2000次配对bootstrap；分别报告已见/未见集合的预测误差、成本与门槛。不足或失败均可完成研究报告，不自动称模型适合P3。

模型试用标准：BER倍数误差中位数≤2、90%分位≤5，Goodput MAE≤.02，在线速度≥10倍；只在BER约1e-4—1e-1、至少20错误且至少10个独立信道的可评价样本上判定。速度按每帧完整链路归一比较，并单列离线建表，避免靠增加Monte Carlo帧数制造加速。

本轮不需要修改接收先验、不训练P3码本、不运行DC或USRP。收益消失或模型失败均保留真实结果。
