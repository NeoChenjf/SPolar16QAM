# 协调协议 — 多载波OFDM瑞利信道分析

## 协议版本

`v1.0-frozen`。三组独立polar块、能量统计、共同装帧、纯能量波形和共享OFDM核心方案均已确认或按明确推荐采用；首版实现若改变这些口径，必须先回写本协议。

## 公共物理口径

| 项目 | 首版口径 |
| --- | --- |
| 调制与编码 | 固定16QAM概率整形polar，SC译码 |
| OFDM | 64子载波，CP比例1/4 |
| 信道 | 无直达径的复高斯频率选择性Rayleigh多径；首版16 taps |
| 收发链 | QAM网格 → IFFT → CP → 多径卷积+噪声 → 去CP → FFT → 单抽头均衡 → LLR → SC |
| SNR | 延续`fixed_esn0`并在README记录标签与实际Es/N0关系 |
| 分组 | 每个realization按`|H_k|^2`排序形成high/mid/low；阈值规则必须固定并落盘 |
| 公平比较 | 同一策略比较点复用相同信道realization、seed、SNR和停止准则 |

## 已确认编码映射

2026-09-17用户确认：首版每个high/mid/low组各使用独立polar块；组内QAM符号只映射到该组真实子载波。不同组可使用不同`p`或纯能量角色。这样可在真实时域OFDM链路中验证分组策略，同时复用现有固定`p`polar模块。

该协议不声称“每个子载波有独立polar码”。若论文必须采用逐子载波编码，需新开增强单元并重新定义码长、码率、交织和复杂度。

### 资源元素装帧协议

- 每个组沿用一套`N=1024`的四bit层polar块，产生1024个16QAM符号；纯能量组仍生成真实波形，但payload为0。
- 三组符号流分别按列填入该组分配到的真实子载波；OFDM符号数取能够容纳最长组符号流的最小值。
- 末尾未占满的资源元素使用显式padding mask，不能计作信息位；Goodput以整个OFDM帧的总时频资源和CP为分母。
- 每个realization的high/mid/low子载波数、OFDM符号数、payload/padding/energy-only mask都必须写入结果表，以便重算。

实现时必须用64子载波的实际分组数量记录padding开销；若padding过大，先以问题记录和smoke证据提出短码或跨组调度增强，不能静默改变码长。

## 策略契约

| 策略 | high | mid | low |
| --- | --- | --- | --- |
| `uniform_p05` | 信息，p=0.5 | 信息，p=0.5 | 信息，p=0.5 |
| `uniform_p03` | 信息，p=0.3 | 信息，p=0.3 | 信息，p=0.3 |
| `uniform_p01` | 信息，p=0.1 | 信息，p=0.1 | 信息，p=0.1 |
| `good_channel_information` | 信息，p=0.5 | 信息，p=0.3 | 信息，p=0.1 |
| `good_channel_energy_shaping` | 信息，p=0.1 | 信息，p=0.3 | 信息，p=0.5 |
| `bad_channel_energy_only` | 信息，p=0.5 | 信息，p=0.3 | 纯能量，p=0.1 |

实现前须对照B3/B4a代码确认本表与现有策略函数完全一致；任何变化先改协议，再改代码。

纯能量组必须发送真实时域波形。首版复用`p=0.1`的概率整形符号生成链，但将该组payload记为0且不把其译码结果计入BER/Goodput；其资源、CP、发送能量和接收能量仍全部进入系统分母与能量统计。若改用确定性多音或其他能量波形，应作为新策略另立名称，不能沿用`bad_channel_energy_only`而不留痕。

## 代码复用协议

从`run_ofdm_baseline.m`的本地仿真逻辑抽取共享OFDM核心，B1退化场景和B4b Rayleigh场景调用同一实现。共享核心至少接收时频网格、CP长度、信道冲激响应、噪声参数与均衡配置，并返回发送/接收采样点、均衡符号和必要元数据。不得复制一套仅供B4b使用的IFFT/CP/FFT流程。

## 指标契约

- BER：信息组的真实信息位错误数 / 真实信息位总数，不按帧数作分母。
- Goodput：信息净码率 × `(1-BER)`，同时计入CP与纯能量子载波占用。
- 发送能量辅助指标：同时保存真实发送QAM符号均方与加CP后的OFDM时域样本均方，用于核对调制分布、IFFT/CP归一化和发射公平性。
- 接收侧能量主指标：使用经过Rayleigh多径、加入AWGN之前的接收信号分量均方，并在去CP前的CP包含口径下统计。
- 接收侧诊断指标：另存相同采样窗口内的含噪接收波形均方；不得用它静默替换主指标。
- 主次关系：策略排序和Pareto默认使用加噪前接收信号均方；含噪接收均方用于诊断；发送端能量作为公平性与机制辅助指标，同时报告以避免把发射功率差异或人工噪声项误判成Rayleigh分配收益。
- 术语边界：上述指标都是发送/接收侧能量代理量，不称RF—DC效率或收获直流功率。
- Pareto：只在相同SNR和同一统计口径内计算，报告离散样本非支配点。
