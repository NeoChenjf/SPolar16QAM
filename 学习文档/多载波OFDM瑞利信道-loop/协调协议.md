# 协调协议 — 多载波OFDM瑞利信道分析

## 协议版本

`v1.0-frozen`。三组独立polar块、能量统计、共同装帧、纯能量波形和共享OFDM核心方案均已确认或按明确推荐采用；首版实现若改变这些口径，必须先回写本协议。

## 公共物理口径

| 项目 | 首版口径 |
| --- | --- |
| 调制与编码 | 固定16QAM概率整形polar，SC译码 |
| OFDM | 64子载波，CP比例1/4 |
| 信道 | 无直达径的复高斯频率选择性Rayleigh多径；首版16 taps |
| 收发链 | QAM网格 → IFFT → CP → 多径卷积+噪声 → 去CP → FFT → 单抽头均衡 → LLR → SC |
| SNR | 延续`fixed_esn0`并在README记录标签与实际Es/N0关系 |
| 分组 | 每个realization按`|H_k|^2`排序形成high/mid/low；阈值规则必须固定并落盘 |
| 公平比较 | 同一策略比较点复用相同信道realization、seed、SNR和停止准则 |

## 已确认编码映射

2026-09-17用户确认：首版每个high/mid/low组各使用独立polar块；组内QAM符号只映射到该组真实子载波。不同组可使用不同`p`或纯能量角色。这样可在真实时域OFDM链路中验证分组策略，同时复用现有固定`p`polar模块。

该协议不声称“每个子载波有独立polar码”。若论文必须采用逐子载波编码，需新开增强单元并重新定义码长、码率、交织和复杂度。

### 资源元素装帧协议

- 每个组沿用一套`N=1024`的四bit层polar块，产生1024个16QAM符号；纯能量组仍生成真实波形，但payload为0。
- 三组符号流分别按列填入该组分配到的真实子载波；OFDM符号数取能够容纳最长组符号流的最小值。
- 末尾未占满的资源元素使用显式padding mask，不能计作信息位；Goodput以整个OFDM帧的总时频资源和CP为分母。
- 每个realization的high/mid/low子载波数、OFDM符号数、payload/padding/energy-only mask都必须写入结果表，以便重算。

实现时必须用64子载波的实际分组数量记录padding开销；若padding过大，先以问题记录和smoke证据提出短码或跨组调度增强，不能静默改变码长。

## 策略契约

| 策略 | high | mid | low |
| --- | --- | --- | --- |
| `uniform_p05` | 信息，p=0.5 | 信息，p=0.5 | 信息，p=0.5 |
| `uniform_p03` | 信息，p=0.3 | 信息，p=0.3 | 信息，p=0.3 |
| `uniform_p01` | 信息，p=0.1 | 信息，p=0.1 | 信息，p=0.1 |
| `good_channel_information` | 信息，p=0.5 | 信息，p=0.3 | 信息，p=0.1 |
| `good_channel_energy_shaping` | 信息，p=0.1 | 信息，p=0.3 | 信息，p=0.5 |
| `bad_channel_energy_only` | 信息，p=0.5 | 信息，p=0.3 | 纯能量，p=0.1 |

实现前须对照B3/B4a代码确认本表与现有策略函数完全一致；任何变化先改协议，再改代码。

纯能量组必须发送真实时域波形。首版复用`p=0.1`的概率整形符号生成链，但将该组payload记为0且不把其译码结果计入BER/Goodput；其资源、CP、发送能量和接收能量仍全部进入系统分母与能量统计。若改用确定性多音或其他能量波形，应作为新策略另立名称，不能沿用`bad_channel_energy_only`而不留痕。

## 代码复用协议

从`run_ofdm_baseline.m`的本地仿真逻辑抽取共享OFDM核心，B1退化场景和B4b Rayleigh场景调用同一实现。共享核心至少接收时频网格、CP长度、信道冲激响应、噪声参数与均衡配置，并返回发送/接收采样点、均衡符号和必要元数据。不得复制一套仅供B4b使用的IFFT/CP/FFT流程。

## 指标契约

- BER：信息组的真实信息位错误数 / 真实信息位总数，不按帧数作分母。
- Goodput：信息净码率 × `(1-BER)`，同时计入CP与纯能量子载波占用。
- 发送能量辅助指标：同时保存真实发送QAM符号均方与加CP后的OFDM时域样本均方，用于核对调制分布、IFFT/CP归一化和发射公平性。
- 接收侧能量主指标：使用经过Rayleigh多径、加入AWGN之前的接收信号分量均方，并在去CP前的CP包含口径下统计。
- 接收侧诊断指标：另存相同采样窗口内的含噪接收波形均方；不得用它静默替换主指标。
- 主次关系：策略排序和Pareto默认使用加噪前接收信号均方；含噪接收均方用于诊断；发送端能量作为公平性与机制辅助指标，同时报告以避免把发射功率差异或人工噪声项误判成Rayleigh分配收益。
- 术语边界：上述指标都是发送/接收侧能量代理量，不称RF—DC效率或收获直流功率。
- Pareto：只在相同SNR和同一统计口径内计算，报告离散样本非支配点。

## 结果契约

每次运行写入`results/YYYYMMDD_HHMMSS_<tag>/`，至少包含README、run_log、CSV、MAT和图；长跑还需progress_log和部分检查点。内部策略ID与显示标签分离，图中不直接显示下划线ID。

## B4b整形审计与等功率比较前置

- 新入口`run_b4b_shaping_audit.m`以相同seed生成旧版固定整形位与payload条件化版本，审计无噪声信息位回环、S/I/F及经验16QAM PMF；不覆盖B4b正式入口或历史结果。
- PMF的target/model按四个16QAM标签bit请求边缘概率的独立乘积枚举；该独立性是假设，需与有限长编码后的empirical联合PMF分别报告。联合PMF未通过单侧95%簇bootstrap TV上界`≤0.05`时，暂停等功率策略统计并查明偏差。
- bootstrap簇为完整Polar码字，并按seed另行汇报；static/smoke只作闭环和诊断，不作为正式PMF门禁。
- 解释有限码长效应时，优先在同一B4分区与映射下对照`N=256/1024`；已有v3 source-MC+GA或不同目标分布的码长结果只能作旁证。若B4经验边缘率不随N靠近请求p，应继续核对目标定义和分区构造，不能把偏差直接归为短码长。
- 后续等功率校准使用含CP与padding的发送时域均方；每策略单一缩放系数在独立校准样本上估计并冻结，验证集相对目标偏差需`≤1%`。所有策略固定同一物理噪声方差，缩放同步进入接收星座与LLR口径。


### 源概率审计补充
条件随机参考必须使用精确源LLR，不能以min-sum logistic冒充精确概率。随机化非I位仍需要I接近源高熵位；F iid均匀只作敏感性对照。比较集合时保留相同K/S数量、消息及决策规则，构造样本独立于评估样本；短诊断不替代正式PMF门禁。

## 2026-10-09 整形构造版本更新与结果边界

阶段B的新实验固定 $K$ 与 $|S|$，按 Bernoulli 源条件熵选取 $S$，再在剩余位置按各信道SNR下的通信GA可靠性选 $I/F$；每帧用当前消息和全零冻结位条件化生成整形位。源熵估计与构造参数在每个 $p$ 固定，不逐帧或逐SNR重估。原B4的GA前缀集合和保护带策略仅为历史版本，须由新训练集重新估计，不沿用旧码本。

构造层证据已通过：$N=1024$五个$p$的联合PMF pooled单侧95%上界为0.0080–0.0262，三个逐seed最大上界为0.0146–0.0274；$N=256/1024$的新消息条件化数据均通过TV≤0.05门禁。独立源熵图和码长对照图见本目录的[偏差定位结论](整形分布偏差定位结论.md)末尾修订及[重建清单](../shaped_polar验证loop/理论更新与图重建/整形理论更新与仿真图重建清单.md)。这些证据不代表OFDM通信改善，也不支撑等功率收益。

正式OFDM六策略数据、约束码本和seed1042/2042验证仍待运行；必须按新构造重新训练、在独立seed上验证，并报告约束不满足率。未完成前，不把旧保护带规则称为当前策略。


## 2026-10-09 纯能量基线语义修正（待smoke验收）

代码审计发现，旧版bad_channel_energy_only虽然把low组排除在BER/Goodput分母外，却仍为该组随机生成信息位并发射，故旧图中的“纯能量”名称与载荷不一致。新版本仅对low组固定零payload，仍使用该组p=.1、原S/I/F构造和消息条件化整形；该组不计为信息子载波。加入零payload断言后再进行B4 pilot/正式运行。历史B4数据保留，但只代表旧定义，不能与修正版本直接合并或作同一baseline结论。

## 2026-10-09 新构造B4正式统计与独立验证

正式训练：`16QAM_Polar/v2/results/20261009_203109_b4_source_entropy_formal/`，seed42、30个Rayleigh realization、SNR标签[20,24,28,32,36,40] dB、六策略、每重复至少5帧、达到200个错误则停、最多50帧。训练重复表1080行、汇总36行、信道表1920行；唯一键、START/DONE、rate/Goodput/padding恒等式、信息子载波比例、逐组payload计数与图审计通过，low组纯能量策略payload one总数为0。正式输出为F10–F15。

训练策略由训练集独立生成：一般最大能量码本在20/24 dB按预定规则回退到最大Goodput的uniform_p05，28–40 dB选uniform_p01。保护带候选在未查看验证集前冻结（训练BER上界≤.08、Goodput下界≥.27，优先最大接收能量；无可行项时最大Goodput回退）。

一般码本的独立验证seed1042目录为`results/20261009_211124_b4_source_entropy_holdout1042/`，分析`results/20261009_223148_b4b_fixed_policy_holdout_analysis/`：28/32/36/40 dB通过原BER上界≤.10和Goodput下界≥.25；20/24 dB是训练时已标注的最大Goodput回退，不算通信门槛通过。符合门槛点的接收能量代理相对uniform_p05为正，幅度约0.0096绝对功率单位（须注意该数据不是等功率实验）。

保护带候选seed2042独立验证目录为`results/20261009_223251_b4_source_entropy_guardband2042/`，分析`results/20261009_230741_b4b_guardband_policy_test_analysis/`：28–40 dB均通过原BER/Goodput门槛；低SNR的20/24仍按预注册规则回退最大Goodput，未声称通过约束。逐SNR策略为28 dB good_channel_information、32 dB good_channel_energy_shaping、36/40 dB uniform_p01；接收RF均方代理相对uniform_p05差值约0.00224/0.00833/0.01063/0.01063。seed2042未参与冻结，结果未用于调参。

边界：三批图均沿用原信道、功率、噪声、Goodput资源分母，用于隔离构造变化。接收能量是加噪前时域均方代理，不等于整流器直流输出；当前策略间发射符号功率不同，也不证明等功率收益。独立样本只支持这套信道/门槛/候选策略的有限验证，不代表任意单次CSI保证。保护带候选通过不意味着整个研究目标完成。
