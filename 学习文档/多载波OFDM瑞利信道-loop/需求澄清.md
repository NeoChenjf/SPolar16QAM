# 需求澄清 — 多载波OFDM瑞利信道分析

## 来源与阶段判定

- 用户要求：先判断单载波多阶调制是否完善；若完善，则在`学习文档/`开启OFDM瑞利信道分析。
- 证据结论：通用8/16/32/64QAM五类门禁已闭合；固定16QAM的BER/Goodput/发送能量同批帧正式实验与审计已完成。
- 因此：本loop不再补单载波主线功能，直接承接阶段B的B4b。

## 研究问题

在频率选择性Rayleigh OFDM中，不同子载波可靠性不同。需要判断：统一整形参数、好信道偏信息、好信道偏能量整形、差信道纯能量传输等策略，在真实有限长polar链路中形成怎样的BER、Goodput与能量权衡。

## 范围内

1. 64子载波、CP、多径Rayleigh、频域单抽头均衡的严格OFDM物理链路。
2. 固定16QAM概率整形polar链路，首版继续使用SC译码和`fixed_esn0`口径。
3. 三个统一基线：`uniform_p05/p03/p01`。
4. 三个自适应策略：`good_channel_information`、`good_channel_energy_shaping`、`bad_channel_energy_only`。
5. BER、CP修正Goodput、信息子载波占比、发送/接收侧能量代理量、Pareto与统计区间。
6. smoke、正式统计和图数审计分层推进。

## 明确不在首版范围

- SCL及非均匀先验译码增强。
- RF—DC非线性整流器、硬件标定、USRP。
- 一开始就运行full mode或论文级长仿真。
- 在同口径六策略比较前宣称某策略最优。
- 把B3 proxy或B4a分组加权结果当成严格OFDM结果。

## 验收条件

1. 统一`p`时，新Rayleigh实现可退化到可解释的AWGN/平坦信道基线，维度、CP和均衡一致。
2. 每一帧确实经过IFFT、CP、多径卷积、去CP、FFT和均衡，不以`|H_k|^2`加权替代时域链路。
3. 六策略使用同一信道样本、SNR、seed与停止准则。
4. 结果目录包含参数、CSV、MAT、README、日志、PNG/PDF/FIG及必要检查点。
5. smoke只证明链路与输出；正式结论必须基于多seed、多realization、足够错误数和置信区间。

## 已确认的架构决策

2026-09-17用户确认采用A方案：按high/mid/low三组建立独立polar块并映射到真实子载波组。该方案最符合现有B2/B3协议且实现风险最低；其准确表述是“分组级独立polar编码 + 严格OFDM-Rayleigh物理链路”，不是64套逐子载波独立编码。

每个子载波独立polar块、单一polar码跨异质子载波两种方案保留为后续增强方向，不进入首版B4b。
