## 答辩口径

- 任务二的能量是归一化发送符号均方，不是RF–DC整流效率。
- 任务三的能量是Rayleigh多径后、加噪前接收信号均方代理量。
- 低复杂度算法是在六项离散码本中进行双QoS约束下的能量最大化；最终28 dB保护带已经第三批独立样本验证，但不是连续全局优化。
- B1/B2/B3/B4a分别是baseline、画像、proxy和smoke；最终结论来自B4b正式统计、配对分析和独立验证。
