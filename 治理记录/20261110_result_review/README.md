# 实验数据保留与精简建议（2026-11-10）

## 结论

存在可精简材料，但最大的一批数据不是简单重复。建议采用“同类默认最新；互补分段、不同随机样本、独立角色、仍被使用的基线例外”的原则。只删除旧批次的raw大文件，保留参数、汇总、图、日志、源码和资产，往往比整目录删除更合适。

本轮仅执行此前批准的两份Python缓存删除，共21427字节，删除前SHA-256与源.py存在性均核对；没有删除任何实验数据。下述为待审议建议，未获数据删除授权。

### A：旧功率路线，建议最先处理

六批参数种子分别8101/8102/8103与8201/8202/8203，说明它们互为独立校准/验证样本，不是同一批重复跑。建议精简的原因是该路线已停止，当前不再用这些raw作模型验收，而非“只保留种子最大的那批”。旧调度events.log与status.json明确记录gate_failed；power_gate.json记录206失败单元、最大总/分组相对误差约1.126%/1.806%。11月实验已改共同环境和噪声口径。

保留六目录的repetitions.csv、params/completed/checkpoint/templates等全部非raw、source_snapshot和旧调度目录内frozen_power/power_gate/日志。汇总可保留失败事实，但不足以完整复核每个原始对象；若未来要研究旧门禁误差机制，raw仍有价值。建议在确认不再逐样本研究旧路线后删除，或先外部冷备份。未发现已验证的异地备份。

### B、C：开发轨迹可以保留记录，原始试跑可精简

B为10月24—25日旧P2协议的27批试跑；C为11月6日42批短pilot/smoke。它们与最新实验的口径、码长/帧数有变化，不宣称数值等价。建议依据“开发过程已完成、现阶段不用逐样本重分析”精简raw，而不是追认旧结果无效。

C明确排除六批被现有测试直接读取的数据：170217策略训练、170258策略测试、171343模型校准、171512seen、220749恢复测试、220751PMF检查点测试。6批完整保留。特别保留213309批次中的templates.mat：11月7日E1和E2参数仍指向它；旧目录不能整批删。所有C目录的PMF/模型/templates和其他非raw均保留。

原文档会保留历史路径；精简后必须在对应目录追加清理说明，标明哪些raw已撤除、汇总支持哪些结论、恢复位置或不可恢复性。未备份时不得称可完全回退。旧代码中的按目录验证器/哈希检查可能不再能在被精简批次执行；这项取舍须由删除决定明确接受。

### D：最新不代表每个文件都应保留

grid内部115209批次是diagnostic_a、1信道×1帧×125候选的冒烟，raw约73.87MiB。后续开发与确认数据完整保留，只建议精简这125个冒烟raw，保留其参数、汇总、完成记录与源码。保存的smoke_dir引用仍指向现存目录，但逐raw回看将不可用。此建议不是删除整个grid。

## “最新优先”的实际核对

[同类比较](same-family-comparison.json)按去日期/UUID后的同名系列分组，65个系列、159组新旧比较。39个旧目录的全部CSV在最新版存在且SHA-256逐字节一致，包括多次BPSK基线、singlecarrier_sc_closure、部分subcarrier_strategy_compare、phaseA_codeonly_gap_analysis、v3 BER refine等。它们适合优先归档旧分析/重绘副本；CSV相同不等于旧MAT、图像/图注、参数及整个目录相同，因此本轮未把它们混入raw删除清单。分类清单单列39项与对应新版，可继续逐项取舍。版本分组仅是线索，不自动把同名不同物理模型归为可替代。

相反，对旧E2和新grid同一combo_01的原始MAT做只读抽查，states与info_counts等相同，但h/H、channel_seed/noise_seeds、frame_hashes、bit_errors和stream_errors不同。说明不能声称最新grid完全覆盖旧E2。详见[saved-mat-comparison.json](saved-mat-comparison.json)。这里只加载两个已保存文件并比较字段，未执行通信链、重新采样或仿真；一格反例足以否定完全相同，不能据此判断两批整体算法差异来源。

## 范围与限制

扫描317个结果目录，含grid的5个子批次；空间按最深匹配目录归属，避免父子重复累计。覆盖v2、v3、OOK及旧results；两份旧月份ZIP和散落MAT未展开作内容等价核验，暂保留。读取README、params及少量完成/分段MAT，检索扫描范围内代码/文档引用；来源和逐批证据见[batch-evidence.json](batch-evidence.json)。复用本机已存在SciPy仅读MAT v5元数据，无安装依赖；MAT v7.3仅抽查两份，不全量解码。CSV仅作字节哈希比较，不重算实验统计。

195个目录尚未完成用途/覆盖语义复核，其中部分列入39个同表旧版候选；它们多是较小的早期分析与绘图批次。“待核定”并非已经证明有用，也并非可删。当前建议先处理能减少约1GiB的A—D，而不是为小文件无限扩大准备。

删除建议不依赖放宽研究验收，也不改历史失败结论。没有新Goal、预测模型修改或实验启动。
